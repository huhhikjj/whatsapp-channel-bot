حتى يعمل البوت 24 ساعة دون أن تترك لابتوبك أو كمبيوترك مفتوحاً، تم تجهيز ملفات Dockerfile و Render / Railway جاهزة للرفع بنقرة زر واحدة مجاناً!

1 ارفع المشروع على مستودع GitHub خاص بك.
2 اربطه بمنصة استضافة مجانية تدعم Node.js (مثل Render أو Railway أو Koyeb أو VPS).
3 افتح رابط لوحة التحكم وامسح الرمز، وسيعمل إلى الأبد في السحابة!

دليل رفع البوت على سيرفر سحابي 24/7 مجاناً

الخيار الأول: الاستضافة المجانية على Render.com (أسهل وأسرع خيار)

  1. أنشئ حساباً مجانياً على GitHub.com ثم أنشئ مستودعاً جديداً (Repository).
  2. ارفع ملفات هذا المجلد إليه.
  3. سجل دخولك إلى Render.com واضغط New + ثم Web Service.
  4. اختر مستودع GitHub الذي رفعته.
  5. في إعدادات Build Command اكتب: npm install
  6. في إعدادات Start Command اكتب: npm start
  7. اضغط Deploy Web Service. ستفتح لك رابط لوحة التحكم الخاصة بك في المتصفح!
  8. افتح الرابط من موبايلك أو الكمبيوتر، امسح كود QR، وسيبدأ البوت بالعمل على السيرفر كل ساعة دون توقف.

الخيار الثاني: سيرفر خاص (VPS - Ubuntu / Debian)

إذا كان لديك سيرفر سحابي خاص (VPS)، يمكنك تشغيله باستخدام PM2 ليعمل في الخلفية دائماً:

git clone <رابط-مستودعك>
cd whatsapp-channel-bot
npm install
npm install -g pm2
pm2 start server.js --name "whatsapp-bot"
pm2 save
pm2 startup
