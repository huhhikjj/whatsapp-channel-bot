# 🕌 بوت أذكار وتذكيرات قنوات الواتساب التلقائي

نظام متكامل واحترافي لجدولة وإرسال الأذكار والتذكيرات بالصلاة على النبي ﷺ تلقائياً إلى قنوات الواتساب (WhatsApp Channels) والمجموعات، مزود بلوحة تحكم ويب تفاعلية وسهلة الاستخدام باللغة العربية.

---

## ✨ المميزات الرئيسية

1. **إرسال تلقائي دوري:** جدولة الرسائل كل ساعة (أو تحديد أي فترة زمنية: 15 دقيقة، 30 دقيقة، ساعتين، إلخ).
2. **دعم كامل لقنوات الواتساب الرسمية (WhatsApp Channels):** يدعم إرسال الرسائل للقنوات بمجرد إدخال معرّف القناة أو رابط الدعوة الخاص بها.
3. **لوحة تحكم ويب فاخرة (Web Dashboard):** تتيح لك مسح رمز الـ QR مباشرة من المتصفح دون الحاجة لأي تعقيدات تقنية في سطر الأوامر.
4. **بنك أذكار وصيغ صلاة على النبي ﷺ:** قائمة مسبقة الإعداد بأجمل الأدعية والصيغ مع إمكانية إضافة، تعديل، وحذف الأذكار بسهولة بضغطة زر.
5. **إرسال تجريبي فوري:** زر "إرسال تجريبي الآن" للتأكد من وصول الرسالة لقناتك فوراً.
6. **سجل نشاط حي (Live Logs):** عرض فوري للرسائل المرسلة وحالة الإرسال (نجاح / فشل) مع التوقيت الدقيق.
7. **جاهز للنشر السحابي (Cloud 24/7):** يعمل على سيرفرات مجانية مثل Render أو Railway ليبقى شغالاً على مدار 24 ساعة دون الحاجة لفتح جهازك الشخصي.

---

## 🚀 طريقة التشغيل على جهازك الشخصي (Local)

1. تأكد من وجود **Node.js** على جهازك (إذا لم يكن مثبتاً قم بتحميله من [nodejs.org](https://nodejs.org)).
2. افتح مجلد المشروع في الـ Terminal وشغّل الأمر التالي:
   ```bash
   npm start
   ```
3. افتح المتصفح على الرابط:
   [http://localhost:3000](http://localhost:3000)
4. امسح رمز الـ QR الظاهر في الشاشة من هاتفك عبر:
   - تطبيق واتساب > **الإعدادات** > **الأجهزة المرتبطة** > **ربط جهاز**.
5. اختر قناتك أو الصق معرّفها، فعّل خيار الجدولة، واضغط **حفظ الإعدادات**!

---

## ☁️ طريقة الرفع على سيرفر سحابي مجاني ليعمل 24/7 دون توقف

لكي يستمر البوت بالإرسال حتى بعد إغلاق الكمبيوتر أو انقطاع الإنترنت:

### الطريقة الأولى: الاستضافة السحابية عبر Render.com (مجاني تماماً)
1. أنشئ حساباً مجانياً على [GitHub.com](https://github.com) إذا لم يكن لديك حساب.
2. أنشئ مستودعاً جديداً (New Repository) وارفع ملفات هذا المجلد إليه.
3. توجه إلى [Render.com](https://render.com) وسجل الدخول مجاناً بحساب GitHub.
4. اضغط على **New +** ثم اختر **Web Service**.
5. اختر المستودع الخاص بك.
6. في الحقول تأكد من الآتي:
   - **Environment:** Node
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
7. اضغط **Deploy Web Service**.
8. بعد دقيقة ستمنحك المنصة رابط موقع (URL) خاص بك، افتحه من الموبايل أو الكمبيوتر وامسح الرمز، وسيعمل البوت للأبد في السحابة!

### الطريقة الثانية: سيرفر خاص (VPS - Ubuntu/Debian)
إذا كان لديك سيرفر خاص (VPS):
```bash
# تثبيت الاعتماديات
npm install
npm install -g pm2

# تشغيل البوت في الخلفية ليعمل بشكل دائم
pm2 start server.js --name "whatsapp-bot"
pm2 save
pm2 startup
```

## ⚙️ ملفات المشروع
- `server.js`: خادم Express ومحرك الجدولة التلقائية.
- `whatsapp.js`: المحرك البرمجي المسؤول عن الاتصال بواتساب وإرسال الرسائل للقنوات.
- `reminders.json`: بنك الأذكار والتذكيرات بالصلاة على النبي ﷺ.
- `config.json`: إعدادات البوت والوقت والموعد القادم.
- `public/`: ملفات لوحة التحكم (HTML, CSS, JS).
- `Dockerfile` & `render.yaml`: ملفات النشر والتجهيز السحابي التلقائي.
